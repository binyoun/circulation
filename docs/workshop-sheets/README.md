# Workshop sheet sources

HTML sources for the printable workshop sheets. Open in Chrome and print (or export with headless Chrome) to regenerate the PDFs in `public/workshop/`.

- `sketch-sheets.html`: Care Memory Sketch Sheet, Glowing Cup Design Sheet, drawing sheet (A3 landscape)
- `group-sheet.html`: Three Hands group sheet (A2 landscape, laminate)
- `printables.html`: finger cards, prompt cards, table card (A4). Uses images from the workshop folder; regenerate from the original folder if images are missing.
